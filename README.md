# Task Manager App

A responsive frontend-only Task Manager application built using React and Tailwind CSS.

## Features

* User Login & Register
* Create, Edit & Delete Tasks
* Task stages:

  * Todo
  * In Progress
  * Done
* Responsive UI
* Loading & Error States
* LocalStorage Persistence

## Tech Stack

* React
* Vite
* Tailwind CSS
* Lucide React

## Assumptions

* This project is implemented as a frontend-only application.
* localStorage is used for task persistence and authentication.
* Backend APIs and database integration were skipped to focus on rapid frontend implementation and user experience.

## Technical Decisions

* Single-file component structure for faster development and simplicity.
* Tailwind CSS used for responsive UI and styling.
* localStorage used to simulate authentication and persistence.

## Deployment

Frontend deployed on Vercel.
